# Python-Student-Management-System
A Python command-line application for managing student records, searching, removing students, and calculating average grades.

Student Management System
A command-line student management system developed in Python as part of my programming studies.

Features

Add students with their names, ages, and grades.
List all registered students.
Search for students by name.
Remove students from the system.
Calculate the average grade.
Validate user inputs and handle common errors.

Technologies

Python 3.10+
Visual Studio Code

How to Run

Install Python 3.10 or newer.
Download the main.py file.
Open a terminal in the project folder.
Run: python main.py

Current Limitations
Student records are stored in memory and are not saved after closing the program.
Searching and removing students by name affects the first matching record.
